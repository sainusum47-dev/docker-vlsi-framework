# Sky130 Standard-Cell Library

This project uses the Sky130 HD typical-corner standard-cell Liberty
library for synthesis, timing analysis, and power estimation.

The Liberty file is excluded from Git because its redistribution terms
have not been verified.

Before running the flow, obtain an authorized compatible library file
and place it here with this exact filename:

sky130_fd_sc_hd__tt_025C_1v80.lib

Then run the project commands from the repository root.
